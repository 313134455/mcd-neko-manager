### 1. 预算 + 营养双约束配餐
告诉 neko 你的预算和需求，她会自动拉取营养数据、门店菜单和你的优惠券，穷举出最优组合。
> 主人：“我今天只有 35 块预算，想吃减脂餐。”
> neko：“主人，neko 帮你找到了三套方案喵~”
> - 【性价比王者】￥28.5｜520 大卡｜蛋白质 32g
> - 【高蛋白优选】￥33.0｜610 大卡｜蛋白质 41g
> - 【均衡控卡】￥31.5｜480 大卡｜蛋白质 28g

### 2. 热量刺客检测
输入你想吃的套餐，neko 会告诉你这顿饭相当于多少运动量。
> 主人：“我想吃巨无霸+中薯条+可乐。”
> neko：“喵！主人，这是热量刺客！”
> - 总热量：890 大卡
> - ?? 慢跑 14.8 公里
> - ?? 跳绳 89 分钟
> - ?? 爬楼梯 178 层
> - ?? 打工人搬砖 178 分钟

### 3. 社交分享卡片
一键生成排版精美的“麦门账单”卡片，直接发小红书/朋友圈。

### 4. 麦门成就系统
记录你的每一次麦门消费，解锁成就徽章：
- ?? 首单麦门
- ?? 热量刺客猎人
- ?? 省钱大师
- ?? 减脂战士
- ?? 麦门信仰
- ? 积分猎人

### 5. 会员积分联动
自动查询积分余额，提醒即将过期的积分，推荐最优兑换方案。

### 6. 专业模式切换
如果不想用猫娘语气，随时说“退出猫娘”，neko 会立刻切换为干练的专业助手。

## ?? 安装与使用

### 前置条件
- 已安装 WorkBuddy（或其他支持 MCP 的客户端）
- 已申请麦当劳 MCP Token

### 第一步：配置麦当劳 MCP
在 WorkBuddy 的「连接器」页面，添加以下 MCP 配置：
```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
